O plugin **AutoCEP** preenche automaticamente os campos de endereço no checkout com base no CEP digitado pelo usuário.

== Descrição ==
O plugin **AutoCEP** preenche automaticamente os campos de endereço no checkout com base no CEP digitado pelo usuário. Ele utiliza a API OpenCEP para buscar o endereço correspondente e é compatível com vários tipos de checkout, incluindo Fluid Checkout e CartFlows.

== Funcionalidades ==
- Preenchimento automático de endereço no checkout com base no CEP digitado.
- Compatível com vários plugins de checkout, como Fluid Checkout e CartFlows.
- Utiliza a API OpenCEP para obter dados de endereço.
- Fácil de integrar e usar.

== Instalação ==
1. Faça o upload do plugin para o diretório `/wp-content/plugins/`.
2. Ative o plugin através do menu "Plugins" no WordPress.

== Uso ==
1. Vá para a página de checkout no seu site WooCommerce.
2. Digite um CEP válido no campo correspondente.
3. Os campos de endereço serão preenchidos automaticamente com os dados obtidos da API OpenCEP.

== Compatibilidade ==
Compatível com:
- **WooCommerce (checkout padrão)**
- **Fluid Checkout**
- **CartFlows**

== Documentação de Terceiros ==
Este plugin utiliza a API OpenCEP:
- https://opencep.com/
